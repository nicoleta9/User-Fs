Proiectul are ca scop monitorizarea activitatii utilizatorilor activi in sistem. In directorul director_radacina se creeaza un director pentru fiecare user real. In directorul utilozatorului se gaseste fisierul procs, care contine PID-ul proceselor initializate de acesta si comanda care a initiat procesul. In cazul in care userul se deconecteaza, fisierul procs se goleste iar in director apare un fisier nou, lastlogin, care contine data ultimei conectari. Informatiile sunt actualizate la fiecare 30 de secunde.
